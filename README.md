# Spring Boot Components & Toolkit

A comprehensive collection of small, reusable component implementations built using **Java** and **Spring Boot**. This repository serves as a reference and practical toolkit for developers working on backend development with Spring Boot.

## 📚 Overview

This project contains multiple Spring Boot applications and components demonstrating best practices for:
- Security & Authentication (JWT)
- File Upload/Download functionality
- RESTful API design
- Spring Data JPA
- Component-based architecture

## 🚀 Getting Started

### Prerequisites
- Java 11+
- Maven
- MySQL/PostgreSQL (for some components)

### Installation

```bash
git clone https://github.com/TejaSin07/spring-boot-components.git
cd spring-boot-components
```

### Running Individual Components

```bash
cd 57_SpringBoot_JWT_App
mvn clean install
mvn spring-boot:run
```
